Mühle

Mühle spielen

Erstelle ein Spiel und schick den Link an einen Freund.

Spielregeln in 30 Sekunden
  1. Setzen: Abwechselnd setzt jeder seine 9 Steine auf freie Punkte. Weiß beginnt.
  2. Ziehen: Danach schiebt man einen Stein entlang einer Linie auf einen freien Nachbarpunkt.
  3. Springen: Wer nur noch 3 Steine hat, darf auf jeden freien Punkt springen.
  4. Mühle: Drei eigene Steine in einer Linie – dann nimmst du einen Stein deines Mitspielers. Steine in einer Mühle sind geschützt, außer dein Mitspieler hat nur noch solche.
  5. Gewonnen hat, wer seinen Mitspieler auf 2 Steine bringt oder so einsperrt, dass er nicht mehr ziehen kann.
